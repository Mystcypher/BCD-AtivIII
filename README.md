# StreamVerse Dynamics - Banco de Dados MySQL

Projeto de Banco de Dados Relacional para uma plataforma de streaming.

## 📌 Conteúdo do Repositório
- `streamverse_dump.sql`: Script completo contendo a criação do banco de dados `streamverse_db`, todas as tabelas, inserção de dados e 15 consultas SQL.

## 🗂️ Tabelas
- `planos`
- `assinantes`
- `perfis`
- `categorias`
- `titulos`
- `historico_visualizacao`
- `pagamentos`

## 🛠️ Tecnologias
- MySQL / MySQL Workbench
